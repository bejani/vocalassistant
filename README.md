# Vocal Assistant — دستیار صوتی اندروید

این پروژه یک نمونه Native Android با Kotlin است که برای استفاده در خودرو طراحی شده است. برنامه با عبارت **«سلام یولداش»** فعال می‌شود، سپس فرمان‌های فارسی مانند «به عبدالله آستانی زنگ بزن» یا «به احمد تماس بگیر» را تشخیص می‌دهد و قبل از تماس، به‌صورت صوتی درخواست تأیید می‌کند. تماس فقط پس از تشخیص عبارت‌هایی مانند «تأیید می‌کنم»، «بله» یا «حتماً» انجام می‌شود.

## پردازش صدا

تشخیص فرمان از `android.speech.SpeechRecognizer` گوشی انجام می‌شود و پاسخ صوتی از موتور داخلی آفلاین `sherpa-onnx` و مدل فارسی ONNX تولید می‌گردد. مدل پاسخ صوتی در اولین استفاده دانلود و در حافظه داخلی برنامه ذخیره می‌شود؛ پس از آن تولید و پخش پاسخ‌ها بدون اینترنت انجام می‌شود.

## اجرا در Android Studio

پروژه را با گزینه **Open** روی پوشه ریشه باز کنید. سپس اجازه دهید Gradle Sync انجام شود و از مسیر `Build > Make Project` کامپایل کنید. برای اجرای واقعی، یک گوشی Android با API 26 یا بالاتر و مجوزهای میکروفون، مخاطبین و تماس لازم است.

پس از نصب، مجوزهای میکروفون، مخاطبین و تماس را بدهید و گزینه **شروع دستیار صوتی** را بزنید. اندروید یک اعلان foreground نمایش می‌دهد؛ این اعلان برای دسترسی مداوم به میکروفون ضروری است.

## محدودیت‌های شبکه در ایران

وابستگی‌های پروژه فقط از Google Maven و Maven Central دریافت می‌شوند. در صورت اختلال دسترسی، می‌توان mirror سازمانی یا mirror قابل‌دسترسی را در فایل `settings.gradle.kts` فعال کرد. mirror نامعتبر یا ناشناس می‌تواند باعث خطای Sync یا دریافت بسته نادرست شود. پس از اولین Sync موفق، Gradle وابستگی‌ها را در cache نگه می‌دارد.

## نسخه‌های سازگار با سیستم فعلی

برای کاهش دانلودهای جدید، این نسخه با Android SDK Platform 34 تنظیم شده است:

```text
compileSdk: 34
targetSdk: 34
minSdk: 26
AndroidX Core KTX: 1.13.1
```

در نتیجه برای build این پروژه نصب بودن Android SDK Platform 34 کافی است و نیازی به API 35 ندارد.

## فرمان تماس با نام مخاطب

بعد از شنیدن پاسخ «بله، در خدمتم»، نام مخاطب را همراه فرمان فارسی بگویید؛ برای نمونه:

```text
به عبدالله آستانی زنگ بزن
به احمد تماس بگیر
```

دستیار نام مخاطب پیدا‌شده را اعلام می‌کند و برای تماس تأیید صوتی می‌خواهد. سپس برای برقراری تماس بگویید «تأیید می‌کنم»، «بله» یا «حتماً». برای لغو، بگویید «لغو»، «نه»، «خیر» یا «انصراف».

## پاسخ صوتی فارسی آفلاین داخلی

این نسخه برای پاسخ‌های صوتی به موتور TTS گوشی، eSpeak NG یا API خارجی نیاز ندارد. دکمه **آزمایش صدا** در اولین اجرا مدل فارسی را از release پروژه دانلود می‌کند؛ پس از اتمام دانلود، تولید صدا با CPU گوشی و بدون اینترنت انجام می‌شود. حجم مدل حدود 109 مگابایت است و اجرای نخست ممکن است چند دقیقه زمان ببرد.

برای اولین آزمایش، گوشی باید به اینترنت دسترسی داشته باشد. بعد از کامل‌شدن دانلود، آزمایش صدا و پاسخ‌های دستیار می‌توانند آفلاین اجرا شوند. مدل فارسی برای استفاده شخصی و رایگان در این پروژه قرار گرفته است و مجوز منبع مدل `CC-BY-NC-4.0` است.

مدل از release زیر دریافت می‌شود:

`https://github.com/bejani/vocalassistant/releases/tag/tts-model-v1`

اگر دانلود مدل قطع شود، فایل موقت حذف می‌شود و اجرای بعدی دانلود را سالم تکرار می‌کند. برای کاهش حجم APK، مدل داخل APK قرار نگرفته و فقط یک‌بار در اولین اجرا دانلود می‌شود. runtime داخلی از طریق `sherpa-onnx` خروجی را مستقیماً با `AudioTrack` پخش می‌کند.

## امنیت

این پروژه به کلید API نیاز ندارد و هیچ کلید، رمز عبور یا توکن GitHub در کد قرار نمی‌گیرد. مدل فقط پس از درخواست کاربر و با مجوز اینترنت برنامه دانلود می‌شود.

## محدودیت‌های نسخه اول

عبارت بیدارباش **سلام یولداش** با شنودهای کوتاه و پیوسته SpeechRecognizer بررسی می‌شود و یک hotword engine اختصاصی کم‌مصرف نیست. برای استفاده طولانی‌مدت، رفتار سرویس به موتور تشخیص گفتار دستگاه و محدودیت‌های سازنده گوشی وابسته است. اگر چند مخاطب مشابه وجود داشته باشد، نسخه فعلی بهترین تطبیق را انتخاب می‌کند؛ برای استفاده حساس بهتر است نام مخاطب‌ها یکتا باشند.
